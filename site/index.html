          How it works
          
        
          
        
            
          
          1. 1
            One file has the rules
            shared.json has the strict flags. Each other preset gets them through extends.
            2. 
          
          2. 2
            Small files add one concern
            esm.json and commonjs.json set the module system. lib.json sets the paths.
            3. 
          
          3. 3
            Your project extends one preset
            init writes a tsconfig.json with one extends line. Paths with ${configDir} resolve from your project.
            4. 
          
          4. 4
            This page reads the real files
            The build reads tsconfig/, starts the real CLI and starts tsc. The page shows that record and types none of it by hand.
            5.
